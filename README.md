## About

BG3 Better Hotbar 2 Config Manager helps you plan and document your hotbar layouts for each character class in BG3. Save layout configurations, track ability assignments and optimize your combat action hotbar setup.

---

## Features

| Feature | Description |
|---------|-------------|
| **Layout Planner** | Plan hotbar slot assignments per character class and build |
| **Ability Groups** | Organize abilities into logical groups for faster combat access |
| **Class Configs** | Save named hotbar configurations per class and playstyle |
| **Quick Reference** | Document key ability positions for each character in your party |
